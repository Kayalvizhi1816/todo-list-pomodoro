# To-Do List + Pomodoro Clock

This project is a simple productivity web application.
It combines a To-Do List with a Pomodoro Clock.
The To-Do List helps users add, complete, and manage their tasks.
The Pomodoro Clock helps users focus on their work using timed sessions.
Users can work for a fixed time and take short breaks.
This project was created using HTML, CSS, and JavaScript.
JavaScript is used to handle tasks, buttons, and the timer functionality.
The project has a simple and user-friendly interface.
It is useful for students and anyone who wants to manage their time.
Through this project, I learned how to create an interactive web application.
I also learned how to use JavaScript for DOM manipulation and timer functions.

## Features

* Add and manage tasks
* Mark tasks as completed
* Delete tasks
* Pomodoro focus timer
* Short break timer
* Simple and responsive interface

## Technologies Used

* HTML
* CSS
* JavaScript

## How to Run

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in a browser.
4. Start adding tasks and use the Pomodoro timer.

## Project Purpose

The main purpose of this project is to combine task management and time management in one simple application.
